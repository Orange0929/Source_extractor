# Source_extractor
<br />

설치법:
<br />
[해당사이트](https://www.ffmpeg.org/)에서 FFmpeg설치
<br />
파이썬 3.12.10 설치
<br />
install_windows.bat 실행 (한번만 실행해도 됨)
<br />
run_windows.bat 실행 후, 인터넷 주소창에 해당 주소 입력
<br />
> http://127.0.0.1:8000

사용법:
<br />
검색된 대사를 클릭하면 해당 항목 바로 아래에 원본의 주변 파형이 펼쳐짐
<br />
파형을 드래그한 뒤 선택 구간을 재생하거나 WAV로 바로 받을 수 있음
<br />
필요하면 선택 구간을 새 검색 클립으로 저장할 수도 있음


지원 기능:
<br />
검색 결과 100개씩 더 보기 / 검색 결과 전체 선택
<br />
선택한 음성 클립들을 WAV로 잘라 ZIP 한 번에 받기
<br />
검색 결과 아래의 파형을 드래그해서 원하는 구간을 WAV로 받거나 새 클립으로 저장
<br />
파형 확대, 구간 반복 재생, 시작/끝 0.001초 단위 입력
<br />
<br />
업데이트할 거:
<br />
피치 파형 표시와 타임 스트레치
<br />
그 외는 RyneHub로 연락주시면 긍정적으로 검토를 한 후 언젠가 구현해봄
<br />
