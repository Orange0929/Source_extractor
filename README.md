# Source Extractor

음MAD 발음 소스를 검색하고, 파형·피치선을 보면서 구간을 선택해 WAV로 추출하는 Windows 로컬 앱입니다. 기존 화면을 WebView2 전용 창으로 실행합니다.

## 기존 사용자가 앱으로 전환하기

1. 기존 서버를 종료하고, 최신 ZIP의 파일을 **기존 프로그램 폴더에 덮어씁니다**. 기존 `uploads`, `data.json`, 캐시 폴더는 지우지 않습니다. 새 ZIP에는 빈 `data.json`을 넣지 않아 기존 프로필이 덮어써지지 않습니다.
2. `install_windows.bat`을 **이번에 한 번** 실행합니다.
3. 바탕화면 **Source Extractor** 또는 `run_windows.bat`을 실행합니다. 브라우저 주소 입력은 필요 없습니다.

설치 중 진행 단계가 창에 표시되며 상세 내역은 `install_log.txt`에 기록됩니다. 첫 설치는 AI 실행 패키지 때문에 시간이 걸릴 수 있습니다. 설치한 폴더는 앱과 자료의 저장 위치이므로 유지하세요.

## 새로 설치하는 경우

Python **3.12.10 (64비트, 설치 시 Add Python to PATH)**와 FFmpeg/ffprobe가 필요합니다. Windows의 **Microsoft Edge WebView2 Runtime**도 필요합니다. 준비 후 ZIP 압축을 쓰기 가능한 폴더에 풀고 위의 2–3번을 진행하세요.

- [Python 3.12.10](https://www.python.org/downloads/release/python-31210/)
- [FFmpeg](https://www.ffmpeg.org/download.html)
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)

## 앱 안에서 업데이트

앱 상단 **업데이트 확인 → 다운로드 및 준비 → 재시작하여 적용**.

이 저장소(`Orange0929/Source_extractor`)의 **main 커밋**을 기준으로 확인합니다. Git이나 `git pull`은 필요 없습니다. GitHub가 공개한 커밋 SHA로 고정한 ZIP을 받아 검사합니다. 처음 ZIP으로 설치한 버전은 `local`로 표시되며, 첫 앱 내 업데이트 후 커밋 번호가 표시됩니다.

새 코드는 `.desktop/versions`에 준비하며 원본 오디오·프로필·클립·피치 캐시를 덮어쓰지 않습니다. 실행 패키지가 같으면 현재 환경을 재사용하고, 달라졌으면 별도 환경에 설치합니다. 다운로드/설치가 실패하면 현재 버전을 유지하며, 새 버전의 시작이 실패하면 이전 버전으로 돌아갑니다. 실행 중인 업로드·분석·다운로드를 마친 후 재시작하세요. AI 모델은 코드 업데이트 때 다시 받지 않습니다.

설치에 쓰는 Python과 FFmpeg는 유지해야 합니다. 버전 변경으로 처음 필요한 모델이 생기면 해당 모델의 첫 다운로드가 필요할 수 있습니다. 이전 버전과 실행 환경은 복구용으로 보관됩니다.

## 문제 확인

- 앱 시작/실행 기록: `.desktop/app.log`, 로컬 서버 기록: `.desktop/server.log`
- 업데이트 패키지 설치 기록: `.desktop/update.log`
- 앱 상단 **진단 로그 저장**으로 위 로그와 버전 정보를 TXT 하나로 저장할 수 있습니다.
- **서버 CMD 열기**는 현재 로컬 서버 주소와 `server.log`의 실시간 출력을 보여주는 디버그 창입니다. CMD를 닫아도 앱은 종료되지 않습니다.
- 앱이 열리지 않으면 WebView2 Runtime 설치 여부를 확인하세요.
- 브라우저 방식이 필요하면 앱을 닫고 `run_browser_windows.bat` 실행 후 `http://127.0.0.1:8000`에 접속하세요. 이 방식은 마지막 정상 적용 버전으로 실행하며, 앱 내 업데이트 버튼은 표시하지 않습니다. 앱과 브라우저 서버를 동시에 실행하지 마세요.

## 개발 검증

연속음 검색에서 `ㄴ아`, `ㄴ 아`, `ㄴ"아"`, `n a`처럼 독립된 자음을 앞에 쓰면
받침 연결 조건으로 검색합니다. 예를 들어 `난 아직`, `신아`처럼 원문에서 ㄴ 받침
다음에 아가 이어지는 구간을 찾고, 단순 `나`는 제외합니다. `ng 을`/`ng을`도 같은
방식입니다. 이 조건에는 유사 음소 검색을 적용하지 않습니다. `나`/`na`는 일반
음소 검색으로 유지됩니다. 받침 위치는 저장된 대사 표기 기준이며 실제 발화의
음절 경계를 오디오에서 판별하는 기능은 아닙니다.

한국어 발음 검색과 연속음 검색은 g2pk2 및 MeCab 형태소 분석을 사용합니다.
된소리되기, 구개음화, ㅎ 변화, ㄴ 첨가, 겹받침, 7종성 중화와 문맥에 따른
일부 발음 변화를 처리합니다. 사투리·고유명사·실제 화자의 발음까지 보장하지는 않습니다.
기존/가져온 프로필은 원래 대사에서 새 검색 키를 계산하므로 재추출할 필요가 없습니다.
변환 결과는 실행 중 캐시하며, 재시작 후 첫 발음 검색은 다시 계산합니다.
이번 의존성 변경 업데이트는 별도 실행 환경을 설치하므로 코드만 바뀐 업데이트보다 오래 걸릴 수 있습니다.
검색 중 추가 다운로드나 pip 설치는 하지 않습니다. ZIP 덮어쓰기 사용자는
`install_windows.bat`를 다시 실행해 의존성을 설치하세요.

Python API 테스트에는 FastAPI/NumPy/ffmpeg 외에 `httpx`가 필요합니다. 데스크톱 업데이트 테스트는 GUI·네트워크·AI 모델 없이 수행할 수 있습니다.

```text
python -m unittest discover -s tests -p test_desktop_update.py -v
python -m unittest discover -s tests -p test_desktop_server.py -v
python -m unittest discover -s tests -p test_profile_roundtrip.py -v
python -m unittest discover -s tests -p test_search_modes.py -v
python -m unittest discover -s tests -p test_korean_offline.py -v
node tests/test_plot_wheel.cjs
node tests/test_editor_transport.cjs
```

Windows에서 WebView2 창, 파일 선택/다운로드 대화상자와 실제 오디오 출력은 별도 확인이 필요합니다.

## Whisper 분석 관리

상단 **⚙ 설정 → Whisper 음성 분석**에서 장치(자동/NVIDIA GPU/CPU), 성능(절전/균형/최대), CPU 스레드 수를 선택하고 **설정 저장**을 누릅니다. 장치·성능 설정은 설정창에 모았으며, 메인 화면에는 분석/대기 작업이 있을 때만 상태와 일시정지·재개·중단 버튼을 표시합니다. 설정은 앱 전체에 저장되며 현재 파일이 끝난 뒤 다음 분석부터 적용됩니다. 동시에 분석하는 파일은 하나입니다. 모델은 파일 사이에 재사용합니다.

설정창을 열면 CPU 이름·논리 스레드 수와 NVIDIA GPU를 자동 감지합니다. GPU 장착 여부와 CUDA/cuDNN 실행 구성 확인 결과를 구분해 표시하며, 실행 구성을 확인하지 못한 GPU는 이유를 표시합니다. 여러 GPU가 있으면 사용할 장치를 고를 수 있습니다. 실제 모델 추론 성공 여부는 첫 분석에서 최종 확인합니다. 장치 검사는 별도 프로세스에서 시간 제한을 두고 수행하며 60초 동안 재사용합니다.

CPU 자원 배정은 **자동(권장)**이 기본입니다. 성능 모드에 따라 자동으로 배정될 스레드 수를 보여주며, **수동 설정**을 골랐을 때만 입력칸을 표시합니다. 입력 범위는 감지된 논리 스레드 수까지입니다.

- **절전 / 균형 / 최대:** 자동 CPU 스레드 수를 각각 논리 코어 수의 약 1/4, 1/2, 전체로 정하고 파일 사이 대기를 조절합니다. 인식 모델·정확도 옵션은 바꾸지 않습니다. GPU 사용률을 일정 %로 고정하는 기능은 아닙니다.
- **일시정지:** 새 파일을 시작하지 않고 현재 파일을 완료한 뒤 멈춥니다. 정지가 완료되면 Whisper 모델 프로세스도 종료해 메모리를 해제합니다. **재개** 시 모델 준비에 시간이 걸릴 수 있습니다.
- **분석 중단:** 현재 파일과 대기 중인 분석을 취소합니다. 현재 파일의 부분 결과는 저장하지 않고 완료된 대사는 보존합니다. 이후 **실패·미완료 음성 재분석**으로 다시 등록하고 **재개**하세요. 업로드 자체는 별도이므로 계속될 수 있습니다.
- 재시작 시 원본에 저장된 대기/분석 중 상태를 복구하여 일시정지 상태로 둡니다. **재개**하면 이어서 분석합니다. 파일 중간부터 이어받지는 않습니다. 기존 대사와 수동 수정 내용은 덮어쓰지 않습니다.
- 화면에는 실제 분석 장치와 전환/실패 원인을 표시합니다. 자동 모드는 GPU 분석에 실패하면 CPU로 재시도하고, GPU를 직접 지정한 경우에는 자동 전환 없이 실패 원인을 표시합니다.

GPU 추론에는 호환 NVIDIA 드라이버 및 CUDA/cuDNN 런타임이 별도로 필요합니다. GPU 선택만으로 설치되지는 않습니다. 현재 faster-whisper 공식 안내는 CUDA 12용 cuBLAS와 cuDNN 9를 요구합니다. [공식 GPU 설치 안내](https://github.com/SYSTRAN/faster-whisper#gpu)를 확인하세요. 이 기능을 위해 기존 CPU PyTorch·피치 실행 환경을 교체할 필요는 없습니다. 피치 분석과 다른 프로그램의 자원 사용량까지 제한하는 기능은 아닙니다.

Whisper 작업은 별도 프로세스에서 수행하고, 완성된 결과만 서버가 기존 데이터 잠금 아래 저장합니다. 작업별 최종 결과·실제 장치는 활동 로그에 기록하며, 분석 프로세스 상세 오류는 설치 데이터 폴더의 `.desktop/stt_worker.log`에 남깁니다. 위 완료/실패/중단 개수는 현재 실행 중 세션의 작업 기준입니다.

개발 검증: `python -m unittest discover -s tests -p test_stt_manager.py`, `python -m unittest discover -s tests -p test_desktop_server.py`.


### 앱에서 GPU 실행 구성 준비하기 (Windows)

GPU가 감지되지만 `cublas64_12.dll` 등을 찾지 못하면 **⚙ 설정 → GPU 실행 구성 설치**를 누릅니다. 분석 중에는 먼저 일시정지를 누르고 현재 파일 완료까지 기다립니다. 확인창에서 동의한 뒤 약 1.1GB의 NVIDIA 공식 Windows 패키지를 PyPI에서 받습니다. 다운로드 중에는 받은 용량/전체 용량과 진행률을 표시하고, 다운로드 후에는 압축 해제·설치 및 파일 확인 단계를 별도로 표시합니다. 완료율은 다운로드 기준이며 압축 해제·설치 단계는 진행 중 표시를 사용합니다. 설치 로그는 `.desktop/gpu_install.log`입니다.

cuBLAS 12.4.5.8, cuDNN 9.1.0.70, CUDA runtime 12.4.127을 앱 데이터 폴더의 `.desktop/gpu-runtime`에 별도로 설치합니다. `--target`과 `--no-deps`를 사용하므로 기존 CPU PyTorch·피치 패키지를 교체하지 않고, 시스템 PATH도 수정하지 않습니다. 받은 DLL 경로는 GPU 감지·Whisper 분석 자식 프로세스에만 등록합니다. 실패하면 기존 구성은 보존하며, 진행 중에는 앱의 정상 종료/업데이트 재시작을 막아 설치 중임을 표시합니다.

설치 후 장치를 다시 확인하고 자동 또는 준비된 GPU를 선택합니다. GPU 설치만을 위해 걸었던 임시 정지는 성공/실패 후 자동 해제됩니다. 사용자가 직접 일시정지했던 대기열은 그대로 유지하므로 이 경우에만 **재개**를 누릅니다. GPU 드라이버/하드웨어 문제까지 해결하는 설치 프로그램은 아니며 실제 모델 추론은 분석 시 최종 확인합니다. GPU 라이브러리는 앱 업데이트와 별도로 사용자가 버튼을 눌러 설치해야 합니다.


일시정지는 현재 실행 중인 대기열의 상태이며, 빈 대기열의 정지 상태를 다음 앱 실행의 기본값으로 가져오지 않습니다. **분석 중단**은 현재 묶음을 취소하며 이후 새 업로드는 자동 시작합니다. 단, 미완료 작업을 재시작 복구했거나 사용자가 현재 대기열을 직접 일시정지한 경우에는 재개를 눌러야 합니다.

대사 수정창에서는 **Enter**로 저장하고 **Shift+Enter**로 줄바꿈합니다. 한글 등 IME 조합 중의 Enter는 저장을 실행하지 않으며, 저장 버튼도 계속 사용할 수 있습니다.


### 추가 검색 옵션

검색 영역의 **추가 검색 옵션** 꺾쇠를 펼치면 **받침만 찾기**와 **한국어·일본어·영어·기타 문자 제외**를 사용할 수 있습니다. 기본은 접힌 상태이며 켠 옵션 수를 제목에 표시합니다. 제외 옵션은 현재 프로필 검색, 더보기와 검색 결과 전체 선택에 동일하게 적용되며 원본 대사를 삭제하거나 수정하지 않습니다. 필터를 바꾸면 이전 일괄 선택은 해제됩니다.

이 필터는 음성을 재분석하거나 Whisper의 언어 판정을 쓰는 것이 아니라 **저장된 글자의 문자 종류**를 봅니다. 혼합 대사는 선택한 문자가 하나라도 있으면 제외합니다. 한국어는 한글·자모, 일본어는 가나·한자(중국어와 공유하는 한자도 포함), 영어는 영문자, 기타는 나머지 문자 체계입니다. 숫자·문장부호·이모지는 언어로 판정하지 않습니다. 한국어·일본어·영어를 모두 제외하면 다른 문자로 잘못 적힌 결과를 찾아 수정할 수 있습니다.
